# Bloxorz - 经典立体翻滚方块

经典益智游戏 Bloxorz 的现代 Web 网页版实现，支持电脑端键盘操作与移动端触控滑动手势。

## 🎮 在线试玩

[点击在线畅玩](https://river8594.github.io/bloxorz/)

## ✨ 特性

- **现代化 3D 等轴测视觉**：深度排序渲染，动态悬崖边缘厚度检测与阴影效果。
- **全平台操作适配**：
  - 🖥️ **电脑端**：支持 `W`/`A`/`S`/`D` 或 `↑`/`←`/`↓`/`→` 方向键翻滚，按 `R` 键快速重新开始。
  - 📱 **移动端**：支持手指触摸自由滑动手势翻滚方块，并配备触屏重置按钮。
- **经典关卡与物理逻辑**：忠实还原关卡拓扑、1x1x2 姿态转移矩阵、悬空掉落与方洞目标判定。
- **纯原生实现**：零外部依赖，极速加载，丝滑 60FPS。
