# 滚动方块 · 十层密室

10 关空间解谜网页游戏。角色按照 1×1×2 的占格规则翻滚，利用横竖姿态、头脚方向与机关寻找出口。

## 游玩

- `three.html`：3D 人物版，作为主要体验。
- `index.html`：轻量 Canvas 版。两种版本共用关卡、规则、成绩和存档，可在设置中切换。
- [项目原有在线试玩地址](https://river8594.github.io/bloxorz/)；线上内容需要随项目发布更新。

在目录中启动静态服务后打开页面：

```sh
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000/three.html`。静态服务使本地存档与提示计算能稳定工作，无需安装构建依赖。

## 操作

方向键 / WASD，或在棋盘上滑动。Z 撤销，R 重试。设置中可开启屏幕方向按钮、音效和减少动态效果。

翻滚方向沿当前等轴测视角映射，键盘、滑动和按钮一致。动画中不堆积方向输入；弹窗打开时暂停棋盘操作。

## 音乐与音效

- 三章分别使用缓慢石牢氛围、空灵炼金旋律和带轻微节拍的机械旋律，循环播放。
- 翻滚包括滚动声与同步落地声，竖立落地更厚重；失败播放坠落提示，薄冰失败增加破裂声；过关使用上行和弦，第 10 关有完整庆祝乐句。
- 机关点亮、回声即将消失与撤销也有独立声音反馈。
- 右上角“♫ 声音”可随时打开设置，分别关闭音乐与音效、调节两种音量。偏好与游戏进度一起保存，已有音效静音偏好保留。
- 新玩家默认开启音乐和音效，首次点击或按键后开始播放；切换到其他页面时暂停，返回后恢复音乐，不重播历史通关或失败音效。
- 所有声音由本地合成生成，无需外部音频资源，两种画面版本共用声音系统。

## 玩法

- **重压机关 ▣**：竖立踩下后永久展开桥梁。
- **薄冰地板**：横躺可通过，竖立会破裂。
- **头脚符文 ☀ / ☾**：太阳需要头端落地，月亮需要脚端落地。完整身体朝向随翻滚保留。
- **回声台 ◇**：竖立登台后离开，留下回声。离台不扣刻度，再完成 3 次翻滚，临时桥收起。等待不会消耗寿命。
- **出口**：竖立进入；有封印的出口先点亮相应符文。

支持完整状态撤销、三级提示、逐关解锁、星级评价、关卡重玩、本地续玩。刷新后恢复最近稳定状态和撤销历史。

过关时人物升起，地板原地渐隐；第 10 关显示总成绩和彩带。中间关展示成绩卡，点击进入下一关。

密室背景随游戏窗口等比铺满、居中裁切，横屏和竖屏均不留黑边；调整窗口时自动适配，过关时继续上下滚动。

## 验证

```sh
node scripts/verify-game.js
```

验证 10 关可解性、核心地形不可绕过、身体端点、回声倒数、薄冰失败、支撑与快照边界，并更新解法记录。浏览器检查覆盖两种画面版本、通关流程、撤销、提示、刷新恢复和手机尺寸。

## 文件

- `game-core.js`：独立于画面的翻滚与机关规则、完整状态、路线求解。
- `levels.js`：10 关地图与机制绑定。
- `game-renderers.js`：3D / Canvas 画面、姿态、出口、足迹与回声。
- `game-app.js` / `game.css`：界面、输入、进度、统计、提示、声音设置和彩带。
- `game-audio.js`：三章背景音乐、翻滚与机关音效、成功与失败乐句、音量和页面播放生命周期。
- `hint-worker.js`：在后台从当前机关状态计算提示。
- `escape-background.js` / `assets/backgrounds/`：三章密室背景，章节变化时渐变切换。
- `vendor/`：固定版本的 Three.js r128 和 GLTFLoader，许可保存在 `THREE-LICENSE.txt`。

3D 角色使用 Polyfork 的 [Kid in a Skeleton Suit](https://polyfork.dev/asset/kid-in-a-skeleton-6bb49d)，从官方 CDN 加载。骷髅服、兜帽、手套和运动鞋沿用原模型，移除手提袋，双臂放下，按实际站姿居中并适配棋盘大小，保留日月端点与翻滚动作。加载失败时用带日月端点的方块继续游玩。玩法和存档不依赖人物资源成功加载。Canvas 版无渲染库依赖。
